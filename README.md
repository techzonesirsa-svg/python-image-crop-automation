# ✂️ Automated HSV Batch Image Cropper (OpenCV & NumPy)

An automated Python computer vision tool designed to scan HSV color profiles and bulk-crop yellow bottom banners, watermarks, or color strips from images with 100% precision.

---

## 🚀 Key Features & Business Benefits
* **Color Isolation (HSV Space):** Uses OpenCV color range masking to detect specific banner hues accurately.
* **Smart Row Scanning:** Scans from bottom up to protect yellow elements in upper parts of images.
* **Batch Automation:** Processes hundreds of images from an `input_images` directory to `output_images` in seconds.
* **Business Value:** Eliminates manual Photoshop/Canva cropping, saving hours of manual labor per batch.

---

## 🛠️ Tech Stack & Requirements
* **Language:** Python 3.x
* **Libraries:** OpenCV (`opencv-python`), NumPy (`numpy`)
